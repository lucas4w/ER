
# Guerra Civis – Glossário

| Termo                   | Definição                                                                                                                                                                                |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Guerras Civis           | Nome do sistema e do jogo de dedução social multijogador. Consiste em uma disputa entre dois times: Máfia e Civis.                                  |
| Máfia                   | Time “vilão” do jogo. Seus membros possuem o objetivo de derrotar os Civis. Geralmente possui habilidades ofensivas.                   |
| Civis                   | Time “bom” do jogo. Devem descobrir e eliminar os membros da Máfia.                                |
| Jogador                 | Usuário que participa ativamente da partida, recebendo um papel e podendo utilizar habilidades e votar.                                                                                  |
| Espectador              | Jogador que está morto ou que entrou após o início da partida. Pode observar o jogo, mas não interfere nas ações ou votações.                                                            |
| Papel                   | Função secreta atribuída a cada jogador no início da partida (ex: Assassino, Médico, Detetive, Juiz). Define as habilidades e o time do jogador.                                  |
| Habilidade              | Poder especial associado a um papel, utilizado principalmente durante a fase da Noite (ex: matar, proteger, investigar, silenciar).                                                      |
| Noite                   | Fase do jogo em que os jogadores com habilidades utilizam seus poderes de forma secreta. O chat geral normalmente fica restrito ou desativado.                                           |
| Dia                     | Fase do jogo em que os jogadores vivos discutem, acusam e votam para eliminar um suspeito.                                                                                               |
| Votação                 | Processo realizado durante o Dia em que cada jogador vivo escolhe um alvo para ser eliminado. O mais votado é eliminado.                                                                 |
| Eliminação              | Remoção de um jogador da partida, seja por ação noturna (assassinato) ou por votação diurna. O jogador eliminado se torna Espectador.                                                    |
| Condição de Vitória     | Critério que determina o fim da partida. A Máfia vence quando o número de máfias vivas é igual ou superior ao de Civis. Os Civis vencem quando todos os membros da Máfia são eliminados. |
| Chat Geral              | Canal de comunicação visível para todos os jogadores vivos durante a fase do Dia.                                                                                                        |
| Chat de Mortos          | Canal de comunicação restrito aos jogadores eliminados (Espectadores).                                                                                                                   |
| Distribuição de Papéis  | Processo automático ou manual de atribuição secreta dos papéis aos jogadores no início da partida, respeitando o equilíbrio entre os times.                                              |
| Resolução de Ações      | Processamento das habilidades utilizadas na Noite, considerando ordem de prioridade e possíveis conflitos (ex: proteção anula assassinato).                                              |
| Status do Jogador       | Estado atual de um participante na partida: Vivo, Morto ou Espectador.                                                                                                                   |
| Configuração da Partida | Conjunto de regras definidas pelo Host antes do início (papéis ativos, tempos de fase, regras de empate, revelação de papéis, etc.).                                                     |
| Log da Partida          | Registro histórico das ações, votações e eventos ocorridos durante a partida, disponível para consulta do Host.                                                                          |
| Reconexão               | Capacidade do sistema de permitir que um jogador que perdeu a conexão retorne à partida mantendo seu estado e papel.                                                                     |
